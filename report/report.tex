    \section{Task 3}\label{sec:task-3}

    The goal of this exercise is to approximate following integrals using MC intergration:

    In Monte Carlo integration we approximate the integral of a function as the expectation value over a certain interval. For the interval [0,1]:

    \begin{equation}
        \label{eq:int}
        Q_n(f) = <f>_n = \frac{1}{n}*\sum_{j=1}^{n} f(x_j) \approx \int_{0}^{1} f(x)= I_d(f)
    \end{equation}

    with

    \begin{equation*}
        \lim_{n->\infty} Q_n = I_d
    \end{equation*}

    There are multiple ways to calculate the error of the approximation that will be discussed in more detail later. For now we will look at the simplest way. As each random draw $x_k$ is random they are uncorrelated and we can write use the variance of the mean as an error approximation:

    \begin{equation}
        \label{eq:variance_of_mean}
        \sigma_{\bar{f}}^2 = \frac{\sigma_f^2}{N}
    \end{equation}

    So the error is directly dependent of the variance of our function f. We can reduce this variance by using importance sampling. What this means is splitting f(x) in the following way

    \begin{equation}
        \label{eq:importance_splitting}
        f(x) = g(x) \times p(x)
    \end{equation}

    where p(x) is a probability density, meaning it is normalized in the interval of interest.

    Plugging \eqref{eq:importance_splitting} into \eqref{eq:int} we get the estimation of our integral $Q_n(f)$ as

    \begin{equation}
        \label{eq:mc_integral}
        Q_n(f)=Q_n(g)=\sum_{j=1}^N g(x_j)
    \end{equation}

    where $x_j$ is distributed according to p(x).
    So by choosing p(x) in a way that reduces the variance the estimation can be improved significantly.

    Sometimes it is possible to obtain a set of values $x_k$, distributed according to a p(x) by using CDF inversion, which is demonstrated on the following example: We are trying to generate random $\tau$ distributed according to $\exp(-\tau)$.
    The results obtained by using CDF inversion can be observed in figure \ref{fig:task3-cdf_histogram}.

    \begin{figure}[h]
        \centering
        \includegraphics[width=0.8\textwidth]{task3/cdf_histogram}
        \caption{Histogram of 100000 random generated values distributed according to p(x), and plot of exact function Q($\tau$) for comparison}
        \label{fig:task3-cdf_histogram}

    \end{figure}

    The histogram is normalized by dividing the counts in each bin with the total number of points and the bin width. $Q(\tau)$ is normalized by solving the equation:

    \begin{equation*}
        \frac{\int_0^5 \exp(-\tau) d\tau = 1}{NORM}
    \end{equation*}

    for NORM and using this constant as a normalization factor for Q. The normalization factor therefore is $1-\exp(-5)$.

    Now that we have $p(x)$ and $f(x)$ (the function to integrate) we can easily obtain $g(x)$ through \eqref{eq:importance_splitting} and evaluate the integrals of the task,

    \begin{equation*}
        I_1 = \int_0^5 \tau \, Q(\tau) \, d\tau, \qquad
        I_2 = \int_0^5 \tau^2 \, Q(\tau) \, d\tau, \qquad
        Q(\tau) = \exp(-\tau),
    \end{equation*}

    using Monte Carlo integration with $N=10^6$ samples drawn via CDF inversion. The error on each estimate is the standard deviation of the mean, $\sigma_{\bar{f}} = \sigma_f/\sqrt{N}$, computed from the sample variance of the integrand. This yields

    \begin{align*}
        I_1 &= 0.9599 \pm 0.0009, \\
        I_2 &= 1.7521 \pm 0.0032.
    \end{align*}

    Both results agree with the analytic values $I_1 = 1-6e^{-5} \approx 0.9596$ and $I_2 = 2-37e^{-5} \approx 1.7507$ within one to two standard deviations, as expected for an unbiased estimator.


    \section{Task 4}

    \subsection{Description and methods}

    The goal of this task is to replicate the sampling of $Q(\tau, \alpha)$ using a Markov Chain Monte Carlo method. Why this is necessary can be observed in section \ref{sec:task-3}. In the CDF inversion we had to find a closed form for $\int_{0}^{x} Q(x') dx'$ and solve the result for $x$. While this works for some low dimensional problems like ours, this sometimes becomes impractical or impossible. In these cases we need a Markov Chain procedure, where we generate samples stochastically by some procedure. (TODO kind of wrong, chain is the important thing)) In this instance the Metropolis algorithm was used, in which the acceptance probability of going from a configuration x to y is given as

    \begin{equation}
        \label{eq:metropolis}
        p_{acc}(x\to y)= \min\left\{ 1, \frac{f(y)}{f(x)} \frac{p_{gen}(y\to x)}{p_{gen}(x\to y)} \right\}
    \end{equation}

    where $f$ is the target distribution. Using this procedure we can directly sample from the normalised distribution $\hat{f}$ without the need for any closed form invertible integral solution, and not even the need to know the normalization constant $Z$ as it is cancelled out in the acceptance probability. \\

    Using the proposed generation probability of just $p(x)=U(0,5)$ works and generates the correct distribution but has a tiny acceptance probability as the target distribution is exponential and therefore has most points in a small region. This can be improved by generating a proposed displacement inside a box around the current iteration point, instead of uniformly generating a new proposal point in the whole interval. I used the following procedure: Generating a proposed displacement of $ \delta * (1-2\xi)$ where $\delta$ is the length of the interval that the current $\tau$ could possibly be displaced to and $\xi$ is a random number in the interval $[0,1]$. If $\tau_{proposed}$ lies outside of the integration interval the move is automatically rejected. This procedure is symmetric, meaning the generation probabilites cancel out. \\

    %todo: need to introduce the observable A at some point

    $\delta$ is a degree of freedom in this procedure and it effects, how big the proposed steps are in the markov chain, so this procedure does not automatically create an acceptance probability that works better than a uniform distribution. Also the individual samples are now highly correlated, as they directly depend on the previous sample. This means we cannot just use equation \eqref{eq:variance_of_mean} anymore to calculate the error as this will greatly underestimate the error. One way to solve this is to perform blocking analysis. We separate our $N$ samples into $M$ blocks of $\frac{N}{M}=B$ samples each. If $B$ is larger than the integrated autocorrleation time $\tau_{int}$ of the observable which is sampled, this means that each block is uncorrelated to any other and the trivial formula for the standard deviation of the mean can be recovered in the following way:

    \begin{equation*}
        \sigma_{\bar{A}}^2 = \frac{\sigma_{A^{(B)}}^2}{M}
    \end{equation*}

    where $A^{(B)}$ is the mean value of observable $A(x)$ in block $B$. \\

    If $\tau_{int}$ is know we can also define an effective number of independent samples $M_{eff}$ and calculate the variance of the mean using $\sigma{\bar{A}}^2 = \frac{\sigma{A}}{M_{eff}}$ where

    \begin{equation}
        \label{eq:m_eff}
        M_{eff} = \frac{N}{2\tau_{int}}
    \end{equation}


    From this we can see that minimizing $\tau_{int}$ is equivalent to maximizing the amount of independent samples for a given $N$ and therefore leads to the lowest possible statistical error in the sample average. Even though this kind of optimization is not necessary for the simple task given, it is nevertheless done for educational purposes in the following way: \\

    Trial values for $\delta$ are chosen from a logarithmic distribution from 0.1 to 100. For each $\delta$ the autocorrelation time is calculated by doing a block analysis. The mean value and variance of the block average for a gradually increasing block size $B$ are calculated with a sample size of $N=1,000,000$. Block sizes where $M<50$ are discarded due to statistical noise. At some block size the variance converges indicating that at this size the blocks are uncorrelated. This value can be inserted into equation \eqref{eq:m_eff} to get $\tau_{int}$. The $\delta$ with the lowest $\tau_{int}$ can be computed this way. This analysis of course quite computationally expensive for real problems and therefore only really makes sense as a starting point if multiple MC simulations for similar problems are computed where the result can be reused. Also the block analysis part for a given $\delta$ is necessary to compute an accurate statistical average.

    The $\delta$ minimization was performed using $N=1,000,000$ samples and using the observable $A(x)=x$ (as we use in I1) and resulted in an optimal value of

    \begin{equation*}
        \delta_{opt}=10
    \end{equation*}

Both very small and very large $\delta$ lead to strongly correlated samples: for small $\delta$ the chain moves in tiny steps and only explores $\tau$-space diffusively, while for large $\delta$ most proposed moves land outside the bulk of the target distribution and are rejected, so the chain repeatedly stays at the same point. The minimum in between confirms $\delta_{opt}=10$.
