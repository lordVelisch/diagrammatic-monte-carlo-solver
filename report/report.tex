    \section{Task 2: Estimating $\pi$}                              % Example sections, subsections

    \subsection{Task description and methods}

    The goal of this task is to estimate $\pi$ using the area method and 1D Monte Carlo integration. Furthermore the convergence speed of each method is observed by gradually increasing the number of samples $N$ and calculating the resulting approximation at each $N$.

    The tool we use to calculate $\pi$ is Monte Carlo integration. This method is now elaborated as the following tasks depend on it. Suppose we want to integrate a function $f(x)$ on the interval $\Omega$ where x can have any number of dimensions. We can multiply the integral of $f(x)$ by 1 in the following way:

    \begin{equation}
        \label{eq:int_base}
        \int_{\Omega} f(x) dx = \int_\Omega \frac{f(x)}{p(x)} p(x) dx
    \end{equation}

    where $p(x)$ is a probability density, meaning

    \begin{equation*}
        \int_{\Omega} p(x)= 1 dx
    \end{equation*}

    By the law of large numbers we can write \eqref{eq:int_base} as the expactation value of $\frac{f(x)}{p(x)}$:

    \begin{equation}
        \label{eq:expect_value}
        \langle \frac{f(x)}{p(x)} \rangle_{p} = \frac{1}{N} \sum_{i=1}^N \frac{f(x_i)}{p(x_i)} \qquad x_i \propto p(x)
    \end{equation}

    for large $N$ where $x_i$ are randomly drawn from the distribution $p(x)$.

    If $p(x)$ is a uniform distribution it is a constant of $\omega$ where $\omega$ is the interval length and can be pulled on the left side resulting in the equation
    
    \begin{equation}
        \label{eq:int_concrete}
        \int_{\Omega} f(x) dx = \frac{\omega}{N} \sum_{i=1}^N f(x_i)
    \end{equation}

    We compare 2 different ways to use this integration to estimate $\pi$.

    \subsubsection{"Integration" method}
    Calculating $\pi/4 = \int_0^1 \sqrt{1-x^2} dx$ using \eqref{eq:int_concrete}
    \subsubsection{Area method}
    Another method is to integrate $\int_0^1\int_0^1 f(x,y) dx dy$ where

    \begin{equation*}
        \[
            f(x,y) = \begin{cases}
                         1 & \text{if } x^2 + y^2 \le 1, \\
                         0 & \text{otherwise.}
            \end{cases}
        \]
    \end{equation*}

    Again inserting this into \eqref{eq:int_concrete} results into

    \begin{equation*}
        \int_0^1\int_0^1 f(x,y) dx dy = 1/N \sum_{i=1}^N f(x_i, y_i)
    \end{equation*}

    By the definition of $f(x)$ the sum corresponds to the number of samples $x_i$ that land inside of the unit circle, which makes the result of this calculation $\frac{\text{\# samples inside the unit circle}}{\text{\# total number of samples}(N)}
    \}$, which is a more intuitive way to think about this method.

    \subsubsection{Error}

    As MC integration is a stochastic method we introduce statistical errors with a finite number of samples $N$. We can quantize this error by using the standard deviation of the mean $\sigma_{\bar{f}}$ where $\bar{f}$ is the expectation value resulting from \eqref{eq:expect_value}. For uncorrelated measurements the standard deviation can be calculated in the following way:

    \begin{equation}
        \label{eq:variance_of_mean}
        \sigma_{\bar{f}} = \frac{\sigma_f}{\sqrt{N}}
    \end{equation}
    
    What this implies, is that an observable with a smaller variance has a smaller statistical error for the estimation. This is the motivation behind using a probability distribution $p(x)$ that minimizes the variance of $\frac{f(x)}{p(x)}$ in equation \eqref{eq:expect_value}. This is called importance sampling and will be used in later tasks.

    \subsection{Results}

    Using a uniform distribution from 0 to 1 with a Mersenne Twister number generation (cite) the methods described above where implemented and the resulting estimation of $\pi$ is given at a respective sample size $N$. The results of this are shown in \ref{fig:task2-convergence}.

    \begin{figure}[H]
        \centering
        \includegraphics[width=0.8\textwidth]{task2/pi_convergence}
        \caption{Convergence of the area and integration methods to $\pi$. The x-axis shows the number of samples $N$ and the y-axis shows the resulting $\pi$ estimation. The horizontal line corresponds to the true value of $\pi$}
        \label{fig:task2-convergence}
    \end{figure}

    It is clearly visually observable, that the integration method converges faster than the area method. The reason for this is that the observable in the integration method has a smaller variance, as can be seen in \ref{fig:task2-distribution}.

    With a fixed value of $N=10^6$ the estimation is repeated for 1000 times and the results are plotted in a histogram. By the smaller spread (variance) is is clearly visible that the integration method results in a smaller variance. Both methods show normal distributions, centered around the true value of $\pi$, which means they converge to $\pi$ as N goes to infinity.

    \begin{figure}[H]
        \centering
        \includegraphics[width=0.8\textwidth]{task2/pi_distribution}
        \caption{Distribution of the area and integration methods to $\pi$. The x-axis shows bins collecting the results of the estimations. The y-axis shows the number of occurences inside the respective bin.}
        \label{fig:task2-distribution}
    \end{figure}

    The resulting mean values are:

    \begin{align*}
        \bar{\pi_{area}} = 3.1416 \pm 0.0016 \\
        \bar{\pi_{int}} = 3.14154 \pm 0.00091
    \end{align*}

    where the error is the standard deviation of the means. In practice you would not have to repeat the estimations for this, but use equation $\eqref{eq:variance_of_mean}$ instead as shown earlier.

    With these results it can be concluded that the integration method is more effective, which means the approximation is on average closer to the real result given the same $N$.

    \section{Task 3}\label{sec:task-3}
    \subsection{Description and methods}

    The goal of this exercise is to approximate following integrals using MC intergration:

    \begin{equation*}
        I_1 = \int_0^5 \tau \, Q(\tau) \, d\tau, \qquad
        I_2 = \int_0^5 \tau^2 \, Q(\tau) \, d\tau, \qquad
    \end{equation*}

    with

    \begin{equation}
        \label{eq:Q}
        Q(\tau) = \exp(-\alpha\tau),
    \end{equation}

    where $\alpha$ is set to 1 for this task and $Q$ is used as an unnormalized probability distribution.

    In the previous section \ref{sec:task-2} the concept of importance sampling was hinted at. For this integration this technique is used by choosing the probability distribution function:

    \begin{equation*}
        p(\tau) = \frac{Q(\tau)}{Z} \qquad Z = \int_0^5 Q(\tau) d\tau
    \end{equation*}

    Now $I_1$ can be solved using \

    \begin{equation}\label{eq:task3_integrals}
        I_1 = Z \times \frac{\int_0^5 \tau Q(\tau) d\tau}{Z} = Z \times \langle \tau \rangle_{Q(\tau)}
    \end{equation}

    where $\langle \tau \rangle_{Q(\tau)}$ is the expectation value of $\tau$ where its values are distributed according to $Q(\tau)$ which can be calculated according to \eqref{eq:expect_value}.
    
    It is not always trivial to find a procedure to generate random samples $\tau_k$ according to some distribution. Sometimes it is possible to obtain a set of values $x_k$, distributed according to a p(x) by using CDF inversion CITE, which is demonstrated on the following example: We are trying to generate random $\tau$ distributed according to $\exp(-\tau)$.

    \subsection{Results}

    The results obtained by using CDF inversion can be observed in figure \ref{fig:task3-cdf_histogram}.

    \begin{figure}[H]
        \centering
        \includegraphics[width=0.8\textwidth]{task3/cdf_histogram}
        \caption{Histogram of $10^5$ random generated values distributed according to $p(\tau)$ using CDF inversion, and plot of exact function p($\tau$) for comparison}
        \label{fig:task3-cdf_histogram}

    \end{figure}

    The histogram is normalized in the following way:

    \begin{equation*}
        \text{height}(bin_i)=\frac{\text{sum}(bin_i)}{N\times w}
    \end{equation*}

    where $w$ is the width of the bin and $N$ the number of samples.

    The normalization factor $Z$ is calculated analytically:

    \begin{equation*}
        Z=1-\exp(-t)
    \end{equation*}

    The final integrals are calculated according to \eqref{eq:task3_integrals} using Monte Carlo integration with $N=10^6$ samples drawn via CDF inversion. The error on each estimate is the standard deviation of the mean, $\sigma_{\bar{f}} = \sigma_f/\sqrt{N}$, computed from the sample variance of the integrand. This yields

    \begin{align*}
        I_1 &= 0.9599 \pm 0.0009, \\
        I_2 &= 1.7521 \pm 0.0032.
    \end{align*}

    Both results agree with the analytic values $I_1 = 1-6e^{-5} \approx 0.9596$ and $I_2 = 2-37e^{-5} \approx 1.7507$ within one to two standard deviations, as expected for an unbiased estimator. One interesting fact to note is the choice of $p$ as being proportional to $Q$. This way the expectation value is only dependent on $\tau$, where we know the variance can at worst be of the same order as $\tau$ in the chosen interval. Had we used a uniform distribution the variance, and therefor the error, could have been far worse as the expecation value would be of the whole function to integrate.

    \section{Task 4}\label{sec:task4}

    \subsection{Description and methods}

    The goal of this task is to replicate the sampling of $Q(\tau, \alpha)$ using a Markov Chain Monte Carlo method. Why this is necessary can be observed in section \ref{sec:task-3}. In the CDF inversion we had to find a closed form for $\int_{0}^{x} Q(x') dx'$ and solve the result for $x$. While this works for some low dimensional problems like ours, this sometimes becomes impractical or impossible. In these cases we need a Markov Chain procedure, where we generate samples stochastically by some procedure. (TODO kind of wrong, chain is the important thing)) In this instance the Metropolis algorithm was used, in which the acceptance probability of going from a configuration x to y is given as

    \begin{equation}
        \label{eq:metropolis}
        p_{acc}(x\to y)= \min\left\{ 1, \frac{f(y)}{f(x)} \frac{p_{gen}(y\to x)}{p_{gen}(x\to y)} \right\}
    \end{equation}

    where $f$ is the target distribution. Using this procedure we can directly sample from the normalised distribution $\hat{f}$ without the need for any closed form invertible integral solution, and not even the need to know the normalization constant $Z$ as it is cancelled out in the acceptance probability. \\

    Using the proposed generation probability of just $p(x)=U(0,5)$ works and generates the correct distribution but has a tiny acceptance probability as the target distribution is exponential and therefore has most points in a small region. This can be improved by generating a proposed displacement inside a box around the current iteration point, instead of uniformly generating a new proposal point in the whole interval. I used the following procedure: Generating a proposed displacement of $ \delta * (1-2\xi)$ where $\delta$ is the length of the interval that the current $\tau$ could possibly be displaced to and $\xi$ is a random number in the interval $[0,1]$. If $\tau_{proposed}$ lies outside of the integration interval the move is automatically rejected. This procedure is symmetric, meaning the generation probabilites cancel out. \\

    %todo: need to introduce the observable A at some point

    $\delta$ is a degree of freedom in this procedure and it effects, how big the proposed steps are in the markov chain, so this procedure does not automatically create an acceptance probability that works better than a uniform distribution. Also the individual samples are now highly correlated, as they directly depend on the previous sample. This means we cannot just use equation \eqref{eq:variance_of_mean} anymore to calculate the error as this will greatly underestimate the error. One way to solve this is to perform blocking analysis. We separate our $N$ samples into $M$ blocks of $\frac{N}{M}=B$ samples each. If $B$ is larger than the integrated autocorrleation time $\tau_{int}$ of the observable which is sampled, this means that each block is uncorrelated to any other and the trivial formula for the standard deviation of the mean can be recovered in the following way:

    \begin{equation*}
        \sigma_{\bar{A}}^2 = \frac{\sigma_{A^{(B)}}^2}{M}
    \end{equation*}

    where $A^{(B)}$ is the mean value of observable $A(x)$ in block $B$. \\

    If $\tau_{int}$ is know we can also define an effective number of independent samples $M_{eff}$ and calculate the variance of the mean using $\sigma{\bar{A}}^2 = \frac{\sigma{A}}{M_{eff}}$ where

    \begin{equation}
        \label{eq:m_eff}
        M_{eff} = \frac{N}{2\tau_{int}}
    \end{equation}


    From this we can see that minimizing $\tau_{int}$ is equivalent to maximizing the amount of independent samples for a given $N$ and therefore leads to the lowest possible statistical error in the sample average. Even though this kind of optimization is not necessary for the simple task given, it is nevertheless done for educational purposes in the following way: \\

    Trial values for $\delta$ are chosen from a logarithmic distribution from 0.1 to 100. For each $\delta$ the autocorrelation time is calculated by doing a block analysis. The mean value and variance of the block average for a gradually increasing block size $B$ are calculated with a sample size of $N=1,000,000$. Block sizes where $M<50$ are discarded due to statistical noise. At some block size the variance converges, indicating that at this size the blocks are uncorrelated. This value can be inserted into equation \eqref{eq:m_eff} to get $\tau_{int}$. The $\delta$ with the lowest $\tau_{int}$ can be computed this way. This analysis of course quite computationally expensive for real problems and therefore only really makes sense as a starting point if multiple MC simulations for similar problems are computed where the result can be reused. However, the block analysis part for a given $\delta$ is necessary to compute an accurate statistical average.

    \section{Task 5}
    \label{sec:task-5}

    The goal of this task is to introduce the notation of Diagrammatic Monte Carlo. We start by considering only $0^{th}$ order diagrams of the following form:

    \begin{equation}
        \label{eq:0th_order_D}
        \begin{tikzpicture}[baseline=-0.5ex]
            % Draw the diagram line
            \draw[thick] (0,0) -- (3.5,0);

            % Node labels below the line
            \node[below] at (0,0) {$0$};
            \node[below] at (1.75,0) {$\alpha$};
            \node[below] at (3.5,0) {$\tau$};
        \end{tikzpicture}
        \quad = D_0(\tau, \alpha) = \exp(-\alpha \tau)
    \end{equation}

    where $D_0$ is the weight of the diagram. It takes a similar form as \eqref{eq:Q}, but in this task $\alpha$ will not be fixed, but also be taken into account in the Metropolis procedure. To achieve this, in each iteration either $\tau$ or $\alpha$ is updated with equal probability. The procedure for updating $\tau$ stays the same as in \ref{sec:task4}, while the proposed $\alpha$ value is drawn uniformly in the set ${0.5,1}$.

Something to note here is that the standard deviation itself is bigger. The reason for this is that we have the same number of samples, but with the added degree of freedom $\alpha$ fewer samples actually contribute to their integrals leaving less total samples per integral.
